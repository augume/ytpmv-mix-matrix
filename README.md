# YTPMV Mix Style Matrix

YTPMV（YouTube Poop Music Video）のMixスタイルを2次元座標上にプロット・管理するWebアプリケーションです。

- **X軸（空間演出）**: ドライ (-100) ↔ ウェット (+100)
- **Y軸（素材加工）**: 素材の味 (-100) ↔ シンセ化 (+100)

## 機能
- **600x600px HTML5 Canvas**: 中央十字軸、補助グリッド、4象限ガイドラベル
- **インタラクティブプロット**: スライダー指定およびCanvas直接クリックによる座標入力
- **同名作者自動更新**: 同一の作者名/トラック名で保存した場合は既存プロットを自動上書き
- **ローカル自動保存**: `localStorage` によりブラウザのリロード後もデータを保持

## 🛠️ 管理者用メモ（荒らし対策・データ復旧手順）

GUIに復元ボタンを表示せず、ブラウザの**開発者ツール (F12 または Console)** から直接バックアップ・復元を行えます。

### 1. データのバックアップ（JSON出力）
ブラウザのコンソールで以下を実行します：
```javascript
exportData()
```
コンソールに全プロットデータのJSON文字列が出力されます。コピーして保存してください。

### 2. データの復元（JSON読み込み）
バックアップしたJSON文字列（または配列オブジェクト）を引数に指定して実行します：
```javascript
importData([
  { "id": "123", "name": "作者A", "x": 50, "y": -20 }
])
```

### 3. 全データの消去
```javascript
clearAllData()
```
ダイアログで確認後、データをリセットします。
