# YTPMV Mix Style Matrix

YTPMV（YouTube Poop Music Video）のMixスタイルを2次元座標上にプロット・管理するWebアプリケーションです。

## 軸構成
- **X軸（空間演出）**: ドライ (-100) ↔ ウェット (+100)
- **Y軸（音作り）**: 素材の味 (-100) ↔ シンセ化 (+100)

## 主な機能
- **600x600px HTML5 Canvas**: 中央十字軸、補助グリッド、4象限ガイド表示
- **座標プロット機能**: スライダー入力および Canvas 上の直接クリックによる座標指定
- **同名作者自動更新**: 同一の作者名/トラック名で入力された場合は座標を自動更新
- **ローカルデータ保存**: `localStorage` によりブラウザ上にプロットデータを保持
